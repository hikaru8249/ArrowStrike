# ArrowStrike 🏹

ブラウザで動くトップダウン型ローグライクアーチャーゲーム。  
スマホでもPCでも、インストール不要でプレイできます。

**▶ プレイはこちら → https://hikaru8249.github.io/ArrowStrike/**

---

## ゲーム概要

ひとりの弓使いとして、押し寄せる敵の群れを倒し続けるサバイバルアクション。  
レベルアップのたびにスキルを選択し、自分だけのビルドで戦略を組み立てろ。

---

## ゲームモード

| モード | 内容 |
|--------|------|
| **ノーマル** | 全30ステージを踏破する本編。最終クリアを目指せ |
| **エンドレス** | ステージ制限なし。どこまで生き残れるか挑戦 |
| **タイムアタック** | 3分間で最多キルを競う。広大な1マップで敵が次々湧く |

## ゲームシステム

### レベルアップ & スキル
- 敵を倒してXPを獲得、Lv.30まで成長
- レベルアップ時に3択のスキルカードから選択
- スキルの合計取得数は **最大30スタック** まで

### ショップ
- ステージクリア後、**ランダムで** ショップが出現（毎回ではない）
- 消耗品・強化アイテム・スキルをゴールドで購入

### 敵・ボス
- ステージが進むほど敵の体力が増加、後半は複数体が同時出現
- ボスは **7種類** が登場、それぞれ固有の攻撃パターンを持つ

| ボス | 特徴 |
|------|------|
| 魔王 | 基本ボス。体力が高く弾幕を放つ |
| 炎魔王 | 炎属性弾。Phase2で3方向射撃 |
| 氷魔王 | 氷属性弾。Phase2で5方向射撃 |
| タイタン | 超大型・超高耐久。体当たりのみ |
| 毒蛇王 | 毒属性弾。Phase2で4方向射撃 |
| 爆弾魔王 | プレイヤー目がけて爆弾を投擲 |
| 影の王 | テレポート能力。Phase2で8方向放射 |

### タイムアタック専用要素
- 広大マップ（通常の約3倍）＋カメラ追従
- 視界は限定的（霧の戦場）
- 30秒ごとに敵の体力が25%増加
- フィールドにランダムショップが時間限定で出現
- ボスが複数回出現

## 技術スタック

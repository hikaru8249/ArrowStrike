# ArrowStrike 🏹

ブラウザで動くトップダウン型ローグライクアーチャーゲーム。  
スマホでもPCでも、インストール不要でプレイできます。

**▶ プレイはこちら → https://hikaru8249.github.io/ArrowStrike/**

---

## ゲーム概要

ひとりの弓使いとして、押し寄せる敵の群れを倒し続けるサバイバルアクション。  
レベルアップのたびにスキルを選択し、自分だけのビルドで30ステージを突破せよ。

- ステージ数：全30ステージ（最終ステージにボスが登場）
- レベルアップ時に3択のスキルカードから選択
- ステージクリア後のショップでさらに強化
- 撃破数・到達ステージのベスト記録を保存

---

## 操作方法

| 操作 | 説明 |
|------|------|
| 画面タップ&ドラッグ | 移動（バーチャルジョイスティック） |
| 自動攻撃 | 最寄りの敵に自動で矢を放つ |

---

## スキル例

| カテゴリ | スキル |
|----------|--------|
| 攻撃 | マルチショット、ピアス、クリティカル、バックショット |
| 元素 | 火炎、氷結、電撃、毒 |
| 特殊 | ホーミング、スプリット、バウンス、チェイン |
| 防御 | シールド、リバイブ、HP再生、ライフスティール |
| 爆発 | メテオ、ストライクブラスト |

---

## 技術スタック

- **言語**: Vanilla JavaScript / HTML5 / CSS3
- **描画**: Canvas 2D API（擬似3Dレンダリング）
- **対応**: PWA（ホーム画面への追加・オフラインプレイ対応）
- **フレームワーク**: なし（ライブラリ不使用）

---

## スマホへのインストール（PWA）

ホーム画面に追加するとアプリのように起動できます。

**iPhone (Safari)**  
共有ボタン →「ホーム画面に追加」

**Android (Chrome)**  
メニュー → 「ホーム画面に追加」
